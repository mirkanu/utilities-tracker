# Requirements: Utilities Tracker

**Defined:** 2026-05-09
**Core Value:** See at a glance how much oil and electricity you're using, know when the oil will run out, and never miss an electricity contract renewal — all from your phone.

## v1 Requirements

### Foundation

- [x] **FOUND-01**: User can log in with a password and stay logged in across sessions — ✓ v1.0 (Phase 1, iron-session)
- [x] **FOUND-02**: User can log out from any page — ✓ v1.0 (Phase 1, logout server action in layout)
- [x] **FOUND-03**: App is accessible via HTTPS on a public URL (Cloudflare Tunnel) — ✓ v1.0 (Phase 1, https://utilities.gsdlabs.dev/)
- [x] **FOUND-04**: App is usable on a phone (mobile-first responsive layout) — ✓ v1.0 (Phase 1, 375px QA in Phase 4)
- [x] **FOUND-05**: User can navigate between Oil and Electricity sections — ✓ v1.0 (Phase 1 BottomNav; extended with Home tab in Phase 4)

### Oil Tracking

- [x] **OIL-01**: User can log a tank height reading (cm + date) — ✓ v1.0 (Phase 2)
- [x] **OIL-02**: User can view history of all tank readings (newest first) — ✓ v1.0 (Phase 2, ReadingsSection)
- [x] **OIL-03**: User can log an oil purchase (date, total litres, total cost £) — ✓ v1.0 (Phase 2; supplier/payee added as quick task)
- [x] **OIL-04**: User can view history of all oil purchases (newest first) — ✓ v1.0 (Phase 2, PurchasesSection)
- [x] **OIL-05**: User can see a graph of tank height over time, with refill events marked — ✓ v1.0 (Phase 2, TankChart with ReferenceLine per purchase)
- [x] **OIL-06**: User can see an estimated date when the tank will run empty (based on consumption rate since last refill) — ✓ v1.0 (Phase 2, segment-based DepletionCard)
- [x] **OIL-07**: Every tank reading displays its litre equivalent alongside the cm value (e.g. "27 cm / ~284 L"), using a calibrated cm→L ratio — ✓ v1.0 (Phase 5, oil-config.ts, 10.5 L/cm)
- [x] **OIL-08**: The depletion prediction and dashboard stat card show litres remaining and litres/day consumption rate — ✓ v1.0 (Phase 5, computeDepletion + OilStatCard)

### Electricity Tracking

- [x] **ELEC-01**: User can log a monthly meter reading (kWh value + date) — ✓ v1.0 (Phase 3)
- [x] **ELEC-02**: User can view history of all meter readings (newest first) — ✓ v1.0 (Phase 3, ReadingsSection)
- [x] **ELEC-03**: User can log a monthly bill (month, total cost £, total kWh consumed) — ✓ v1.0 (Phase 3; billing period dates added as quick task)
- [x] **ELEC-04**: User can view history of all bills (newest first) — ✓ v1.0 (Phase 3, BillsSection)
- [x] **ELEC-05**: User can see a graph of monthly electricity usage (kWh) over time — ✓ v1.0 (Phase 3, UsageChart BarChart)
- [x] **ELEC-06**: User can see a graph of monthly electricity cost (£) over time — ✓ v1.0 (Phase 3, CostChart BarChart)
- [x] **ELEC-07**: User can enter/edit the active electricity contract (provider name, unit rate p/kWh, contract type fixed/variable, expiry date) — ✓ v1.0 (Phase 3; standing charge p/day added as quick task)
- [x] **ELEC-08**: User sees an in-app warning when the electricity contract is within 90, 60, or 30 days of expiry — ✓ v1.0 (Phase 3, ContractExpiryBanner — amber 31-90d, red ≤30d)

### Dashboard

- [x] **DASH-01**: User sees a home screen with key stats for both utilities (current oil level cm, estimated days/date to empty, last electricity bill cost & kWh, contract expiry countdown) — ✓ v1.0 (Phase 4, dashboard with OilStatCard + ElectricityStatCard + ContractExpiryBanner)
