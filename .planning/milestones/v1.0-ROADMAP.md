## Milestone Summary

**Key Accomplishments:**
1. Shipped full-stack Next.js 15 app to production in 19 days from zero — Hetzner VPS + Docker Compose + Cloudflare Tunnel
2. Oil domain: segment-based depletion prediction using readings since last purchase; avoids naive all-time slope
3. Electricity domain: all 8 ELEC requirements including contract expiry warning banner with 3 tiers (amber/red/hidden)
4. Unified dashboard: parallel server-side fetch, OilStatCard + ElectricityStatCard in grid, mobile-first 375px QA
5. Oil cm→L conversion: calibrated 10.5 L/cm ratio wired throughout readings, chart, depletion card, and dashboard
6. Quick tasks: standing charge + billing period dates, supplier/payee field, visible form labels, dashed oil chart

**Key Decisions:**
| Decision | Outcome |
|----------|---------|
| DATE columns only (not TIMESTAMP) | ✓ Good — no TZ issues for daily readings |
| TZ=Europe/London in Docker Compose | ✓ Good — BST handled correctly |
| iron-session for auth | ✓ Good — no session table, simple cookie |
| Segment-based oil depletion | ✓ Good — refill events handled correctly |
| Separate meter readings + bills tables | ✓ Good — no forced reconciliation |
| 10.5 L/cm calibration constant in oil-config.ts | ✓ Good — single source, easily updated |
| Recharts via shadcn ChartContainer | ✓ Good — consistent theming |
| Next.js 15 + shadcn v4 + Tailwind v4 | ✓ Good — tw-animate-css (not tailwindcss-animate) |

**Issues Resolved:**
- BST midnight offset bug: dates appended with "T12:00:00" before recharts parsing
- CookieStore adapter for iron-session v8 middleware (read-only cookies in middleware)
- create-next-app pinned to @15 (npm latest resolves to 16.x which renames middleware.ts)

**Technical Debt / Quick Tasks Applied Post-Phase:**
- Electricity standing charge (p/day) added to contract; billing period start/end dates replacing billing month; auto-calculated cost
- Oil purchases: supplier/payee field added; historical data seeded
- Visible field labels on all log popups (oil readings, purchases, elec readings, bills, contract)
- Oil chart: dots with dashed connecting lines replacing continuous solid line
